# Wizard Sleep

Sleep anywhere without a bed.

## Features

* Right-click the block directly under you
* Then run `/sleep confirm`
* Skips night instantly
* Heals the player
* Works in singleplayer and multiplayer

## How to Use

1. Stand on a solid block
2. Look down and right-click the block under your feet
3. Type `/sleep confirm`
4. Night is skipped

## Requirements

* Minecraft (Fabric)
* Fabric Loader
* Fabric API

## Installation

1. Install Fabric Loader
2. Install Fabric API
3. Put the mod `.jar` into your `mods` folder
4. Launch the game

## Notes

* Only works at night
* You must click the exact block under you
* Does not work in mid-air or on non-solid blocks
